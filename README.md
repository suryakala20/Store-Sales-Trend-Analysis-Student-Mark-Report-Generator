Problem Statement 1: Store Sales Trend Analysis 
A retail store maintains a record of the number of items sold each day for a month.
You are required to build a program that analyzes this monthly sales data.
Your program should:
•	Read the sales numbers for all days of the month into a single-dimensional array
•	Display the sales data in its original order and also in sorted order
•	Find and display the total sales for the month, the highest single-day sales, and the lowest single-day sales
•	Allow the user to search for a particular sales value and display whether it exists in the data
•	Create a backup copy of the sales data
•	Compare two sets of sales data (original and another entered by the user) and display whether they are equal
Your final output should clearly present the sales values, summary statistics, search results, and comparison results.

Problem Statement 2: Student Marks Report Generator 
A college wants to analyze the marks scored by students in an internal test.
You are required to develop a program that processes and reports on these marks.
Your program should:
•	Read the marks of all students into a single-dimensional array
•	Display the marks in the order they were entered and also in sorted order
•	Identify and display the total marks, the highest mark scored, and the lowest mark scored
•	Allow the user to search for a specific mark and show whether it is found
•	Maintain a backup copy of the marks data
•	Compare two sets of marks entered by the user and determine whether they are identical
Ensure that your final output clearly shows the marks, summary findings, search results, and comparison results.
